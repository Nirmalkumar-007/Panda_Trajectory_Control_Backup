### **Overview**
---
#### **YAML Input files**

- `.yaml` : Contains adjustable input parameters used by the main program.  
   
  - ***Note:** Ensure all parameter values are within safe operating limits before starting the experiment.*
------
#### **LOG DATA'S**
- `Trajectory_log/pandaTrajectory_log_split.csv` : stores the log values with **separate headers and units - for MATLAB** that are obtained during trajectory.

   - ***Note:** Log values are appended to the same file after each execution.*
         - *Please back up or rename the file before starting a new experiment to avoid overwriting data.*
---
#### **DATA PLOTTING**

-  `plotting_matplot/Plotting (pandaTrajectory_log_split)` : Contains the Python script used to visualize the recorded trajectory log data.
